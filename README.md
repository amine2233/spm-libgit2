# libgit2-spm

libgit2 with libssh2 and OpenSSL (`libssl`, `libcrypto`) as prebuilt XCFrameworks for Swift Package Manager.

Platforms: iOS 13+ (device arm64, simulator x86_64 + arm64), Mac Catalyst (x86_64 + arm64), macOS 10.15+ (x86_64 + arm64).

## Usage

```swift
.package(url: "https://github.com/amine2233/libgit2-spm", from: "<release tag>")
```

```swift
.product(name: "libgit2", package: "libgit2-spm")
```

## Release a new version

`Package.swift` is generated by the release workflow. Do not edit it by hand.

1. Move the submodules to the versions you want:

   ```bash
   git submodule update --init
   git -C External/libgit2 fetch --tags && git -C External/libgit2 checkout v1.9.7
   git -C External/libssh2 fetch --tags && git -C External/libssh2 checkout libssh2-1.11.1
   git -C External/openssl fetch --tags && git -C External/openssl checkout openssl-3.5.9
   ```

2. Commit the new pointers and push to `main`:

   ```bash
   git add External
   git commit -m "chore: bump libgit2 to 1.9.7"
   git push
   ```

3. On GitHub: **Actions → Release → Run workflow**, branch `main`.
   - `release_tag` is optional. Empty means the libgit2 version (`v1.9.7` becomes `1.9.7`).
   - Set it when rebuilding the same libgit2 version with other dependency versions (for example `1.9.8`). An existing tag makes the run fail.

4. The workflow builds the zips, creates a draft release, regenerates `Package.swift` with the new URLs and checksums, commits it to `main`, tags that commit and publishes the release.

5. Pull `main` (it now contains the `Package.swift` commit) and use the new tag in your project.

If a run fails before the last step nothing is published; fix and run again. If it fails during publishing, the tag and the `Package.swift` commit already exist: publish the draft release by hand, or delete the tag and the draft and rerun.

## Build locally

Requires Xcode, `cmake` and `perl`. Run in order from the repository root; zips land in `lib/`.

```bash
git submodule update --init
bin/build_openssl.sh
bin/build_libssh2.sh
bin/build_libgit2.sh
bin/generate_package.sh <tag>   # rewrites Package.swift, discard with git checkout Package.swift
```

Logs are written to `/tmp/<lib>-<PLATFORM>.log`.
